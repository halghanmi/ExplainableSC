# Systematisation of Transparency, Accountability and Understandability in Blockchain Smart Contracts

## Overview

This repository contains the supplementary material for the article titled **"Systematisation of Transparency, Accountability and Understandability in Blockchain Smart Contracts."**

The replication package includes the following files:

- **Data Extraction and Initial Coding**  
  Contains the list of selected studies and the concepts extracted from each study. The extracted statements are organised according to the three analysed concepts: **transparency, accountability, and understandability**.

- **Classification into Synthesis Levels**  
  Contains the identification of the system context for the extracted concepts and their classification into **low-level and high-level elements**, followed by their mapping to the synthesis levels.

- **Final Synthesis**  
  Presents the final synthesis of the results across the **five levels: output, algorithm, external data, process, and application**.

- **Developer Answers**  
  Contains the responses provided by developers that were used in the study.
